DanClub Open Terminal 是一个完全非盈利、无付费墙、无返佣引流的个人开源金融数据项目。除了作者个人隐私外，全部前端代码、数据导出模板、隐私防火墙脚本与聚合后的公开市场 JSON 接口均无偿开放给社区使用与二次开发。

零隐私泄露：三层物理隔离架构

  1. 只读白名单采集层：导出脚本以 SQLite mode=ro 只读模式仅读取公开行情/公告/统计表，物理不触碰任何私聊、账户或密钥文件。
  2. 本地 Fail-Closed 隐私防火墙：发布前递归扫描每一个 JSON 字段，一旦命中邮箱、手机号、私钥/Token 模式、内网地址或私密词立即熔断阻断发布。
  3. 单向静态 CDN 分发：公网访客与 API 调用方仅访问静态托管边缘节点，永远无法反连数据采集宿主机。
