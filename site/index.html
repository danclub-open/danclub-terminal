DanClub Terminal 是非盈利、无付费墙、无返佣引流的个人开源金融数据项目。全部前端界面、只读白名单导出器、Fail-Closed 隐私防火墙与聚合后的公开 JSON 接口均无偿开放给社区使用与二次开发。

零隐私泄露防线

  1. 只读白名单采集：导出脚本以 SQLite mode=ro 只读模式仅读取公开市场表，物理不触碰私聊、个人账户或密钥文件。
  2. Fail-Closed 隐私防火墙：发布前递归扫描每一个键名与字段，命中邮箱、手机号、私钥/Token、内网地址或私有黑名单即熔断中止发布。
  3. 单向静态分发：公网与 API 调用方仅访问只读静态边缘节点，源数据节点永不直接暴露。
