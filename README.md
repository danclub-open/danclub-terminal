- **开源协议**：MIT License
- **核心理念**：深色精密终端设计、1:1 零畸变矢量图表、毫秒级多空空战战情室 + 实体去重巨鲸阵营雷达，除作者个人隐私外全部源码、导出器、隐私防火墙与开放 JSON 接口均无偿开放。

## 核心频道（7 大模块）

1. **总览与 5 秒交易员决策层**
   - 顶部自动合成 **市场态势（Regime）+ 高优先级异常雷达**（巨鲸阵营背离、QDII 高溢价避坑、币安极端负费率、MSTR mNAV 折价、远月深贴水安全垫）；
   - 7 项底部共振观察矩阵（明确区分 `DeFiLlama 全口径稳定币` 与 `USDT + USDC 双龙头供给`）、恐慌贪婪仪、BTC 矿机关机价、美债 10Y 近 14 日曲线、跨市场宏观映射（真实常规盘涨跌幅 + 52 周高点回撤 + 休市/盘前状态标注）及场内美股 QDII 溢价风险榜；
   - 支持深/浅色主题与「绿涨红跌 / 红涨绿跌」一键切换。
2. **⚔️ 多空空战战情室 · 巨鲸雷达**
   - **60fps HiDPI 战术空战 Canvas**：浏览器直连公开成交 WebSocket，按单笔成交体量分层出击（光束 `<$5万` / 轻型战机 `≥$5万` / 重型截击机 `≥$25万` / B-2 隐形轰炸机 `≥$100万`），绿军多头 vs 红军空头实时对决；
   - **在场实盘巨鲸母舰压阵**：实盘千万~亿级巨鲸按实体去重常驻左右空域，金环标注 `S/A 级聪明钱`、紫环标注 `C 级反指巨鲸`，悬停/点击展开单舰多币种仓位与历史轨迹抽屉；
   - 支持 **副屏全屏挂机模式**、**可选 Web Audio 战术音效** 与 **一键导出战报海报图**。
3. **跨市场套利实验室**
   - 海力士 ADR×10 vs 韩股、黄金 XAU vs XAUT/PAXG 价差带（72h 均值 ±1σ Z-Score + 14 天区间带）；

   - 四所（Binance / OKX / Bitget / Gate）充提安全状态雷达（Fail-Closed 机制）。
4. **资金流与杠杆雷达**
   - 美国 BTC/ETH 现货 ETF 资金流矩阵（智能非对称零轴柱状图、连流天数与极值日）；
   - Strategy (MSTR) 持仓、SEC 8-K 披露与 mNAV 曲线；
   - Hyperliquid 全网持仓、援助基金回购与费率；
   - 币安 U 本位杠杆异动与极端费率双维雷达（同时捕获 1h OI 急增与极端正/负资金费率）。
5. **模拟实验室与在期活动**
   - 3 套纯虚拟模拟定投策略（`FIXED` / `VA` / `MAFG`）净值与分标的对照；
   - 自动剔除过期公告与返佣参数的公开活动清单。
6. **高信噪比市场快讯**
   - 分类配额保障（快讯 / 交易所公告 / 情报预警）、近重复去重与关键词实时筛选。
7. **免鉴权开放只读 JSON API**
   - `/api/v1/{index,overview,whales,arb,flows,labs,feed}.json`，支持 CORS `*`，可直接接入脚本、Bot、Excel 或 Notion。

## 安全与零隐私架构（三层物理隔离）

```text
[公开数据源 SQLite (mode=ro)]
       │ 只读白名单导出 (exporter/public_terminal_exporter.py + scripts/whale_public_exporter.py)
       ▼
[本地 Fail-Closed 隐私防火墙 (scripts/privacy_guard.py)]
  ├── 递归扫描所有键名与字符串（拦截邮箱/手机号/私钥/Token/内网IP/私有黑名单）
  ├── 剥离所有推广返佣参数、非 https:// 链接与噪声标签
  └── 命中任意违规项即熔断中止发布（exit code 2）
       │ 内容哈希防缓存 + SHA-256 白名单校验 (scripts/sync_public_data.py)
       ▼
[静态 CDN / 边缘节点分发] ──▶ 全球免鉴权只读访问（源机零暴露）
```
